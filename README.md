# Pro E-Commerce

## Project structure

- `frontend/` contains the React storefront, Vite config, and public assets.
- `backend/` contains the Express API, database, payments, security, scripts, and tests.
- `android/` contains the Capacitor Android project.
- Root config files coordinate the frontend build, backend server, and deployment.

## Commands

- `npm run dev` starts the API with the frontend in development mode.
- `npm run build` builds the frontend and bundles the backend server.
- `npm start` starts the production server.
- `npm test` runs backend tests.
- `npm run db:init` initializes the database schema.
